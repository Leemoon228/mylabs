## Лабораторная работа №1: Регулярные выражения

### Валидация написания переменной PATH (простое)

Регулярное выражение:

```regex
PATH=/[A-Za-z0-9_.-]{1,255}(/[A-Za-z0-9_.-]{1,255})*(:/[A-Za-z0-9_.-]{1,255}(?:/[A-Za-z0-9_.-]{1,255})*)*$
```

```text
PATH=/ - прямое совпадение с текстом "PATH=/"

[A-Za-z0-9_.-]{1,255} - символы из названий, {1,255} означает диапазон таких символов

(\/[A-Za-z0-9_.-]{1,255})* - начинается с "/" дальше символы из названия от 1 до 255.
* - повтор группы любое кол-во раз (и ноль тоже если директория/файл в корне)


(:\/[A-Za-z0-9_.-]{1,255}(?:\/[A-Za-z0-9_.-]{1,255})*)* - те же две группы что и до этого, но теперь начинается на ':'. '*' в конце показывает что у нас может быть любое кол-во дополнительных директорий (прим. PATH=/bin:/bin:/bin:/bin:/bin)

$ - конец строки (чтобы не захватывать такие кадры - 'PATH=/bin :/usr' )
```

#### Тесты

```text
Правильные:
PATH=/bin
PATH=/usr/bin
PATH=/usr/local/bin
PATH=/usr/local/bin:/usr/bin:/bin
PATH=/home/user/bin

Неправильные:
PATH=
PATH=/
PATH=/bin :/usr
PATH=usr/bin/
PATH=./bin
```

### Валидация типов языка C с вложенными контейнерами (Сложное)

Важное замечание: регулярное выражение проверяет не весь язык, а мэтчит только несколько базовых типов 

Поддерживаются базовые типы: void, bool, char, int, float, double, А также контейнеры - vector, list, map

```regex
(?<![^ \t\r\n])(?(DEFINE)(?<type>(?:void|bool|char|int|float|double)|vector<(?&type)>|list<(?&type)>|map<(?&type),(?&type)>))(?&type)(?![^ \t\r\n])
```

```text
(?<![^ \t\r\n]) - отрицательный lookbehind.
Проверяет символ слева от текущей позиции.

[^ \t\r\n] - любой символ, кроме:
    пробела
    \t - табуляции
    \r - возврата каретки
    \n - переноса строки


Это нужно, чтобы не замэтчить int внутри следующего:
integer
vector<int
myint


(?(DEFINE)...) - блок определения вспомогательного шаблона.
Сам по себе текст внутри этого блока не потребляется.
здесь определяется именованная группа type,
которую потом можно вызывать.


(?<type>...) - именованная группа с именем type.
Она описывает, что считается допустимым C++ типом.

(?:void|bool|char|int|float|double) - базовые типы.

|vector<(?&type)> - тип вектора с рекурсией на type что был до этого.

Внутри находится (?&type), поэтому туда можно поставить
не только int, но и другой контейнер (map, vector или list)

нужно для создания матриц:

vector<int>
vector<vector<int>>
vector<vector<vector<int>>>

|list<(?&type)>|map<(?&type),(?&type)> - оставшиеся типы контейнеров с рекурсией (у map указывается 2 типа, поэтому он сначала сделает рекурсию на первый, а потом на втрой)

list<int>
list<vector<float>>
list<list<vector<double>>>
map<char,vector<double>>
map<vector<int>,list<float>>

(?&type) - непосредственно уже вызов группы что описали ранее



(?![^ \t\r\n]) - уже после вписанного типа отрицательный lookahead.

Точно такой же как и lookbehind, позволяет удостовериться что у нас к определению типа ничего не (прилипает)


```

### Тесты

```text
Правильные:
int char                        # оба идут в match
vector<bool>
vector<vector<map<int,char>>>
list<map<float,float>>
map<char,vector<double>>



Неправильные;
integer
vector<>
vector<int                      # этот в мэтч не пойдет
vector<double>>
map<char>
```
