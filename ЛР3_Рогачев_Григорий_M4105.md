# Лабораторная работа №3: Метрики

Добавление метрик в сервис мониторинга серверных узлов с использованием Prometheus и Grafana.

## Технологии

* Python, FastAPI
* prometheus-client
* Prometheus
* Grafana
* Docker Compose

## Метрики

### Стандартные

| Метрика                         | Тип       | Описание                       |
| ------------------------------- | --------- | ------------------------------ |
| `http_requests_total`           | Counter   | Количество HTTP-запросов       |
| `http_request_duration_seconds` | Histogram | Время выполнения HTTP-запросов |

### Продуктовые

| Метрика                    | Тип     | Описание                            |
| -------------------------- | ------- | ----------------------------------- |
| `nodes_created_total`      | Counter | Количество созданных узлов          |
| `nodes_deleted_total`      | Counter | Количество удалённых узлов          |
| `node_status_checks_total` | Counter | Количество проверок состояния узлов |

## PromQL

### HTTP Requests Rate

```promql
sum(rate(http_requests_total[5m]))
```

### HTTP Latency p95

```promql
histogram_quantile(
  0.95,
  sum(rate(http_request_duration_seconds_bucket[5m])) by (le)
)
```

### Продуктовые метрики

```promql
increase(nodes_created_total[5m])
increase(nodes_deleted_total[5m])
increase(node_status_checks_total[5m])
```

Эти запросы показывают количество событий за последние 5 минут

## Prometheus

Метрики приложения собираются Prometheus через endpoint `/metrics`.

Target: `server-monitoring-api` — **UP**.

![Prometheus Targets](img/lab3/prometheus_targets.png)

## Grafana

Dashboard `Server Monitoring` хранится в `grafana/dashboards/service-dashboard.json`
и автоматически загружается через provisioning. Источники Prometheus и Loki
также задаются в `grafana/provisioning/datasources/datasources.yaml`.

Панели:

* HTTP Requests Rate
* HTTP Latency p95
* Nodes Created
* Nodes Deleted
* Node Status Checks

![Grafana Dashboard](img/lab3/grafana_dashboard.png)

## Запуск

```cmd
docker compose up -d
```

* Приложение: `http://127.0.0.1:8000`
* Метрики: `http://127.0.0.1:8000/metrics`
* Prometheus: `http://127.0.0.1:9090`
* Grafana: `http://127.0.0.1:3000`
