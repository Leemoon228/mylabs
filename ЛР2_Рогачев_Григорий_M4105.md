# Лабораторная работа №2 - OpenAPI

## Сервис мониторинга серверов

REST API сервиса мониторинга серверов и сетевых узлов с использованием OpenAPI Specification и API-first подхода.

### Технологии

* Python
* FastAPI
* Pydantic
* OpenAPI 3.1
* Uvicorn

### Запуск

```powershell
.venv\Scripts\activate
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Swagger UI:

```text
http://127.0.0.1:8000/docs
```

### API Endpoints

| Метод  | Путь                      | Описание                    |
| ------ | ------------------------- | --------------------------- |
| GET    | `/nodes`                  | Получить список узлов       |
| POST   | `/nodes`                  | Добавить узел               |
| GET    | `/nodes/{node_id}`        | Получить узел               |
| PUT    | `/nodes/{node_id}`        | Обновить узел               |
| DELETE | `/nodes/{node_id}`        | Удалить узел                |
| GET    | `/nodes/{node_id}/status` | Проверить состояние узла    |
| GET    | `/health`                 | Проверить состояние сервиса |

### Примеры запросов

#### Проверка состояния сервиса

```text
GET /health

HTTP 200
{"status":"ok"}
```

#### Создание узла

```text
POST /nodes

{
    "name": "Test server",
    "host": "127.0.0.1",
    "port": 8000
}

HTTP 201
{
    "id": 3,
    "name": "Test server",
    "host": "127.0.0.1",
    "port": 8000,
    "description": null
}
```

#### Получение узла

```text
GET /nodes/2

HTTP 200
{
    "id": 2,
    "name": "Updated server",
    "host": "127.0.0.1",
    "port": 8080,
    "description": null
}
```

#### Обновление узла

```text
PUT /nodes/2

HTTP 200
{
    "id": 2,
    "name": "Updated server",
    "host": "127.0.0.1",
    "port": 8080,
    "description": null
}
```

#### Проверка состояния узла

```text
GET /nodes/2/status

HTTP 200
{
    "node_id": 2,
    "status": "down",
    "response_time_ms": null
}
```

#### Ошибка при отсутствии узла

```text
GET /nodes/999

HTTP 404
{
    "code": "NOT_FOUND",
    "message": "Node with id 999 not found"
}
```

#### Удаление узла

```text
DELETE /nodes/2

HTTP 204
```

#### Проверка валидации

```text
POST /nodes

Некорректные значения полей

HTTP 422
```
