## ЛР6: CI

GitHub Actions workflow `.github/workflows/ci.yml` запускается при push в `main`

Workflow делает

* Ruff lint
* компиляцию пайтон кода
* API тесты через `curl`
* сборку Docker образа без публикации
* запуск всей Docker инфраструктуры и проверку связности API
